STEP 6
The .data section declares and initializes static memory, 
specifically defining the string labeled hello. The la instruction loads the memory address 
of that hello string into register a0 to pass it as an argument to the system.
The a7 register is loaded twice because it holds the system call codes that tell the
operating system which specific action to perform: 4 to print a string, and 10 to exit the program.
